Build 17 is the submitted review build and uses a later nine-frame\nset. The old JPEG/PNG masters, manifests, and redesign brief were removed from the\nactive tree so they cannot be mistaken for current UI direction; Git history keeps\ntheir audit trail.\n\nThe remaining metadata and privacy drafts are historical working documents. Verify\nall store text, privacy declarations, prices, screenshots, and the exact binary in\nApp Store Connect before using them for another submission.\n\nDurable claim boundaries still apply:\n\n- “Encrypted on your device” covers readable health records in the local SQLCipher\n  database. Account access and subscription entitlement use operational cloud\n  services.\n- “No AI” is a permanent product constraint.\n- Patterns describe saved observations and visible missingness; they do not\n  diagnose or identify causes.\n- Reports summarize user-recorded observations and are shared only through an\n  explicit export.\n- Store screenshots must use synthetic records and the actual current app UI.\n
