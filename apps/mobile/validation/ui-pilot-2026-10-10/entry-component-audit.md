# Today / Record entry component audit

Date: 2026-10-10. Base: Build17 (`cf12e70`), branch `feat/record-hub-build17-2026-10-10`. Scope: every entry surface reachable from production Today and Record, including nested selection, edit, history, and confirmation surfaces. This is a presentation inventory and consistency pass; typed contracts and clinical meaning stay in their existing domains.

## Actual route map

Production shell wiring in `lib/experience/letter_experience_shell.dart` supplies `onOpenRecord`, `onOpenRecordSection` and named `onOpenSymptom` to Today. V5 Today Bleeding opens the expanded bleeding controls; actual pinned symptoms (or clearly labeled curated quick symptoms when no pins exist) open the full-screen editor directly. Named Today edits return to the retained Today route, while ordinary Record edits retain their list and scroll. Sleep opens the Sleep editor; Private note opens Record Notes. All records opens the complete Record hub. Today keeps its own Moment sheet. The date on every Record editor is the selected experienced date, while product episode dates remain separate actual start/stop/effective dates.

## Shared grammar and bounded corrections

Shared native material: Build17 theme/typography, `ExperienceSpacing.screenMargin`, section label → related controls → optional detail, one focused task per editor, no per-field card wall. Ordinal values use `RecordOptionScale`; duration catalogs plus exact entry use `RecordDurationPicker`; categories remain chips with themed selected checkmark and native press feedback; date controls use `InteractionSurface` and native single-date picker. All touch families keep at least 44 logical pixels, optional values start missing, repeat-selection clearing remains caller-owned, and Reduce Motion is respected by the shared touch/scale material.

Actual interventions corrections in this pass: replace duplicated action duration chips with the shared duration component; replace six long check-back degree chips with the shared ordinal component; ensure categorical checkmarks use the theme's on-surface color and busy controls are disabled; align date controls, section labels, margins and Save button radius with Context forms; theme the iOS date popup; use exact-minute keyboard grammar without changing parsing; show manager pending/loading state; retain focused editor draft guards, local save errors, and durable success before returning.

No domain, repository, schema, catalog value, input range, recorded date, source ID, dose string, unit, method, version, action/check-back distinction, or exact-number contract is changed. Shared presentation is not a shared clinical interpretation. Static inventory and focused tests are recorded here; native visual coverage is reported separately by the root agent and is not assumed from widget tests.
