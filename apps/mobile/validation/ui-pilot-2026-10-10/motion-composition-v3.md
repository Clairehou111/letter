# Record V3：前景工作面，而非四个平面 tab

2026-10-10。**用户对 V2 的视觉验收不通过，优先于上一份技术范围内的 PASS。** V2 已改善类别组织，但参考视频里的空间层次、内容接续与动作形变没有真正出现在主要体验中。上一份 PASS 只能解释为没有发现该样板的可用性阻断，不能作为用户满意或视觉目标达成的依据。本文件是下一轮有限实施提案，没有修改产品代码。

## 一个明确方向

保留四个有名字的类别与其挂载状态，**把它们呈现为一个有两层背衬的前景工作面：点击类别时，旧工作面退后，新工作面接到前景；点击症状时，该项从自己的位置展开；保存动作在原位置改变状态。** 层次存在于一个 Record 工作区，不再给每个字段套卡片。

正常状态也要看得到构图变化，而不只在开发录像中捕捉到短动画。标题／日期／类别位于背景工具区；内容在有边界、有温暖表面、有两道露出的背衬边缘的前景工作面。文字始终正面阅读。类别决定内容，不用于推断健康等级。

## 对照实际参考

再次查看用户视频的 `panel-sequence.jpg`、video-2 `frame-004`（堆叠滑动）、`frame-006`（从各自位置聚拢）、`frame-007`（按钮运行状态）并对照 V2 原生图。

| 视频中的机制 | V3 中必须实际出现的对应机制 |
| --- | --- |
| 面板分层浮起 | 静止时露出两个较窄背衬；触碰与切换使前景／背衬的间距发生可见变化。不能仅画两条线而所有层始终不动。 |
| 堆叠切换与 next scale | 点击类别也可驱动接续：旧面缩小退后，新面从侧后方接到前景，工具区不动。无需强迫用户学拖动。 |
| 从各自位置聚拢 | 症状项在自己的点击位置开始扩展到专注编辑区域；关闭沿同一关系收回。不是在列表下方突然插入控制组。 |
| 按钮运行状态形变 | Save note 从可点击 → pending → 保存结果改变宽度／图标／标签；不只是页面下方多一行消息。 |

不采用示例的 90° 倾斜文字、健康值透视卷轴、把事实甩走的手势或无任务的液滴。保留的美感来自可见的层次、受触碰影响的空间关系与准确的状态接续，不能再降级成下划线移动加淡入。

## 静态构图与 Build17 材质

```text
Record                                         Done
calendar  Fri, Oct 9                 Recording today
Symptoms     Daily life     Products     Notes

        ┌──────── 第二道背衬 ────────┐
      ┌────────── 第一道背衬 ──────────┐
    ╭─────────────────────────────────╮
    │ 当前任务的小标题                 │
    │                                 │
    │ Symptoms：选一项 → 展开 degree   │
    │ Daily life / Products：命名列表  │
    │ Notes：文字 → 会改变状态的保存   │
    │                                 │
    ╰─────────────────────────────────╯
Saved on this day                       chevron
```

使用现有 `ExperienceColors`，不重新设计背景：canvas `#1E1224`，前景 `surface #281A30`，专注区域／近背衬使用 `surfaceWarm #33223C` 的适当混合；ink `#F7EEE6`、inkSoft `#CDB6C6`；唯一饱和动作色为 ember `#E4573D`。背衬只显示边缘与材质，不复制未激活章的文字，不制造假的健康摘要。阴影使用已有 plum-black shadowWarm 的低透明度，绝不加白色发光边。

正常宽度工作面左右约 16–20 pt，前景圆角约 26–28 pt；背衬分别向内收 8 / 16 pt、向上露出 8 / 16 pt，圆角跟随前景。卡片顶缘有一条安静的已有暖色 hairline；其它三边更弱。一次只有一个完整内容面；内部命名行、degree 组与输入不再有各自大外框。

工作面占工具区与底部回看之间的可用高度，内部独立滚动，不按内容长度使四章整体高度跳动。短列表的留白可以保留。Notes 文字起点与其它章标题对齐，保存位置跟随输入任务。大字优先阅读与滚动，不强守固定内容高度。

## Storyboard：实施时要看到什么

### 1. Symptoms → Daily life：约 320 ms，真正接续工作面

| 时刻 | 可见状态 |
| --- | --- |
| t0，触点落下 | 类别文字／底色立即响应，active 语义立即改变。内容不等待动画才能操作；触点本身不是产品装饰。 |
| 0–90 ms | 原工作面向切换方向的反侧移动约 24–32 pt、下移约 6 pt、scale 从 1 到 .97；两层背衬间距短暂增加约 4 pt。旧内容开始降低重量。 |
| 60–240 ms | 新工作面从切换方向约 40–48 pt、下方约 10–12 pt、scale .96 接到前景；旧／新两面最多短暂共存，不让两段文字在同一透明平面上交叠。新内容在 120 ms 左右已清楚可读。 |
| 240–320 ms | 新面在目标位置短弹簧收敛；最多一次小于 2 pt 的回弹，scale 不超过 1.004。背衬回到 8 / 16 pt 的稳定间距。日期与回看入口始终原地。 |

方向由类别顺序决定；非相邻跳转不把中间类别逐个演一遍。下划线继续表达位置，但只是内容接续的辅助。快速反向点击从当前位置改向，取消旧目标；不等待旧动画结束、不队列回放。已保存值不随层次变形。

用有限 translation + scale + spring settling 表达纵深，避免 perspective rotation。推荐近临界阻尼弹簧，目标约 300–340 ms 收敛；Flutter 参数可从 mass 1 / stiffness 420 / damping 36 起调，实测限制回弹幅度。参数是调试起点，不是性能已经达标的声明。

### 2. 点 Cramp：从发起项展开，约 280–320 ms

按压 60–80 ms 给原项轻压入，松开后原项的名字沿其起始 rect 进入专注标题位置；专注面从原项附近扩到同一前景工作面的主要编辑区域。名字与标题关系可追踪，degree 在展开的后半段约 100–180 ms 出现。不要先飞一张空卡片再加载所有文字。

在专注态，搜索与 pinned 退为一个清楚的 `Change symptom` 返回动作；Daily impact / Bleeding 退到两个短摘要入口，不继续占据同等视觉重量。六位 degree 是焦点，选中值的完整文字紧邻。专注面不另加第二个永久大卡壳。局部完成动作命名 `Close symptom`，与页顶离开 Record 的 `Done` 分开。

关闭沿同一关系收回到发起项；来源项已滚出 viewport 时使用工作面顶部稳定锚点，不飞出屏幕。页面没有可定位来源项的深入口，如 Patterns initialSymptom，可从工作面顶缘展开同一专注结构。保存值、重复选择移除、已有 picker 生命周期均沿用。

### 3. 点 degree / Save note：可触知回应，结果不抢跑

- Degree 触点落下立即压入至约 .96–.97，已提交选中态沿用边界＋check；相关小图柱从旧值到新值约 160–200 ms 接续，不让整组容器都弹跳。持久化成功才出现 local saved 状态；失败还原正确已存态并保留重试草稿。
- Note 有文字时，保存按钮就是明确的前景动作；down 即压入约 .97，release 收回约 120 ms。提交后同一按钮的图标／标签变为 spinner＋`Saving`，宽度在约 160–180 ms 内保持中心或右缘锚定。成功以后变为 check＋`Saved`，约 180–220 ms；附近仍保留真实日期和 Undo。失败变 `Try again`，草稿不消失。新草稿输入后回到 `Save note`，旧 Saved 不冒充新内容。
- 持久化快于过渡也立即提交真实状态，动画从当前形态继续接到结果；不得人为延迟写入、加最低 loading 时间或在点击时先做成功勾。按钮宽度允许随大字自然增长，不能截掉 Saving / Saved。

## 可执行边界

当前四个 mounted pane、隐藏草稿与各自滚动位置保留。前景过渡需要在约 320 ms 内同时可见 incoming 与 outgoing：用同一固定顺序的四 pane 在稳定 Stack 中变换，或等价的保留状态呈现；不能用替换 child 的 AnimatedSwitcher 导致 note controller / picker draft 重建。过渡结束后非当前 pane 回到不可见／不可交互状态，暂停 ticker，排除辅助功能。旧 pane 在过渡期间也不可响应指针；只让一个当前任务拥有语义与输入。

背衬只由轻量绘制／Container 构成，IgnorePointer、ExcludeSemantics，不截图／缓存用户健康文字作假面板。症状展开可以测量发起项在工作面中的 rect；动画过渡中的名字是装饰性接续，真实 picker 仍由同一个会话实例持有，不能创建两份会写数据的编辑器。没有来源 rect 时提供稳定退化路径。

首轮全部点击可完成，不增加 compulsory drag；Notes 的选择／横向编辑手势保持。saving 禁用类别与冲突导航。换类别只改变视图、保留草稿；换日期、Done、子编辑检查所有隐藏草稿。持续 async generation / mounted / date guards、durable callback、条件 Undo、typed source、0 / missing、Period range / 每日 flow 独立、schema 18 不变。

Reduce Motion 下去掉空间 translation / scale / spring，可用不超过 100 ms 的短交接或即时换面；静止背衬、当前分类、完整标签、pending / saved / error 保留。触感如沿用只能是辅助，不能等待或用它补救无可见响应。

产品范围：按用户决定移除 Letter Archive 和独立 Preparation Plan 入口，保留现有 Cycle reflections 与 Comfort Kit；不在这轮动效工作里再创一个档案库／准备计划。Pattern tracking 的设计另行进行，不扩大 clinical scope。根代理处理对应入口实现与 IA 审计。

## 这次验收不能再只看完成态截图

1. 一个正常原生尺寸的静止图能看见前景工作面与两层背衬，仍保留 Build17 背景、明确日期和四类名称。
2. 同一段实际操作录像包含 Symptoms → Daily life → Products → Notes → 反向返回；必须看到面板的退后／接前关系，不能只有 underline 变化。保存 Notes 在原按钮位置能看到 pending / saved 或真实快速成功接续。
3. 原生录像包含点 pinned symptom → 从发起位置展开 → 点 degree → 关闭收回。开始、中途、结束各抽一帧，说明变化并非简单在列表下方插入字段。
4. 快速反向切两次无旧页面闪回、无排队等待；未保存 note 往返仍在；隐藏 note 换日 / Done / 子编辑继续受保护；无重复写入。
5. 现有 regression 与 analyzer 通过；普通屏幕没有 clipped action，Reduce Motion 没有丢失状态。静态图与录像均不能独立证明 FPS 或 physical haptics。

交付应先完成这个 Record 有限样板供用户触碰，再决定向其它页面推广。V3 成功的标准是用户能实际看到并感觉到「这一面接到前面、这一项从这里展开、这个动作变成了结果」，而不是代码中存在几个 AnimationController。
