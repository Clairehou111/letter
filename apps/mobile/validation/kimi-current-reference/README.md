# Curated Build17 UI reference

These ten normal-size iPhone screenshots are the only retained pre-Kimi visual
reference set. They are synthetic V4 evidence, selected from the superseded
multi-round capture directories so an agent does not ingest failed attempts,
duplicate frames, obsolete preparation/archive entrances, or large videos.

Use them selectively to understand the starting visual problem. The current
V6 source is newer than these images; they are not a pixel target and do not
validate the current branch.
