# Release evidence

These records describe checks performed on specific builds, devices, and
dates. They do not make an untested release gate pass. The active 2.0 gate
summary is in [specs/features/release-2.0/validation.md](../specs/features/release-2.0/validation.md).

| Directory | Contents |
| --- | --- |
| [1.0](1.0/) | TestFlight builds, App Store review submission, purchase/legal checks, and the handoff for submitted Build 17. |
| [2.0](2.0/) | Earlier implementation and simulator evidence, UI checks, and physical-device checklists for the target release. |

Use synthetic records in all validation artifacts. Document the tested commit,
build, environment, reviewer, date, exact result, and unresolved defects when
adding evidence.
