# Letter Within Technology Stack

## Confirmed

| Area | Decision |
| --- | --- |
| Repository | One production monorepo with separate deployable apps |
| Mobile | Flutter and Dart |
| Backend | Python with FastAPI |
| Validation | Pydantic v2 |
| Database | PostgreSQL managed by Supabase |
| Authentication | Supabase Auth |
| Subscriptions | RevenueCat with Apple and Google billing |
| Health storage | Drift + SQLite3MultipleCiphers on iOS/Android; no readable server copy in P0 |
| API contract | OpenAPI generated by FastAPI and consumed by mobile |

Health-record computation is deterministic and on-device. No AI/LLM provider
or model is part of the product: health records are not sent for AI reading,
rewriting, summarization, suggestions, or interpretation. Supabase supports
operational account services, and RevenueCat supports subscription and
entitlement operations only.

## Deferred

- state-management package
- API hosting provider
- optional end-to-end encrypted backup design
- production observability vendors

Do not select deferred dependencies before the feature that needs them is
specified.

Web is a development-preview target only. It uses an in-memory health
repository and must not persist readable health records in browser storage.
