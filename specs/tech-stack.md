# Letter Technology Stack

## Confirmed

| Area | Decision |
| --- | --- |
| Repository | One production monorepo with separate deployable apps |
| Mobile | Flutter and Dart |
| Backend | Python with FastAPI |
| Validation | Pydantic v2 |
| Database | PostgreSQL managed by Supabase |
| Authentication | Supabase Auth |
| Subscriptions | RevenueCat with Apple and Google billing |
| Health storage | Encrypted local database; no readable server copy in P0 |
| API contract | OpenAPI generated by FastAPI and consumed by mobile |

## Deferred

- exact encrypted SQLite package
- state-management package
- API hosting provider
- cloud LLM provider and model
- optional end-to-end encrypted backup design
- production observability vendors

Do not select deferred dependencies before the feature that needs them is
specified.
