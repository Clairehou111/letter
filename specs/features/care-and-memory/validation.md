# Care and memory acceptance

Status: existing automated/simulator evidence is retained under
[`validation/2.0/`](../../../validation/2.0/); final device, accessibility,
and SP6/LV3 clinical review remain open.

| Case | Required result |
| --- | --- |
| Five entrances | Every mode opens directly, responds, offers an exit and correct safety/medical route, and works with Reduced Motion. |
| No inferred record | Entry, gesture, skipped check-back, elapsed time, and unsaved text create no health rating or outcome. |
| Explicit check-back | Better/Same/Worse creates one local event; Skip creates none; delete and unpin have separate effects. |
| Memory | Stable action IDs, Kit item inclusion/removal/replacement, Quick note and cycle reflection editing, and retrieval after period date edits. |
| Safety/privacy | Crisis and physical boundaries remain reachable; no Care text or mode leaks to account, logs, API, or immediate analytics. |
| Care relief | Self-paced guidance, anatomical art, cat lifecycle, Reduced Motion, and qualified SP6/LV3 review pass the release contract. |

Do not treat simulator art review as qualified clinical sign-off. Record the
tested build, device, reviewer, and any adverse response before closing a
release gate.
