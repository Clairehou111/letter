# Archive Story And Pattern Views Validation

Status: proposed

- Story never contains generated interpretation presented as user meaning.
- Pattern values trace to confirmed local records and show missingness.
- Clinical values show provenance and never include unresolved candidates.
- Incomplete cycles are not presented as complete.
- Deleting source records updates every view.
- Archive does not expose drafts, clipboard data, contacts, medication data, or
  cloud content.
- Six or more cycles remain scannable at phone width and large text.
