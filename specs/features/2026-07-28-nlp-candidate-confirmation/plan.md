# Deterministic Candidate Confirmation Plan

Status: proposed; optional-LLM step superseded by the permanent no-AI product constraint

2. Implement deterministic on-device phrase matching and negation handling.
3. Build the review and correction UI with no auto-save of candidates.
4. Do not add the previously proposed cloud LLM adapter; no AI or network path
   may read or interpret health records.
