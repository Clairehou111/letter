## Requirements

- Preserve published Build17 Quiet Dusk canvas and existing Letter Within tokens/components.
- Today presents compact truthful cycle state, one Moment state card with all twelve feelings, and named Body / Sleep / Private note shortcuts. The complete Record route remains available; Moment stays Today-only.

- Period dates appear in one connected range calendar, with editable endpoints, same-day / cross-month support and explicit ongoing state. Record's day calendar stays single-date.
- Touch feedback starts immediately; selected, pending, saved and error remain distinct. Saved follows the existing durable write completion. Reduce Motion keeps all information and actions without spatial movement.
- No domain/data/application storage changes, schema migration, repository API changes, fake daily flow, altered period review/merge/stale rules, clinical calculation changes, or entitlement changes.
- A backward-compatible optional typed presentation navigation intent may open Body, Sleep or note in Record; existing callers remain valid and origin routes/draft guards are preserved.
