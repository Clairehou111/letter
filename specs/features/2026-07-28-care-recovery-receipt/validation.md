# Care-Linked Recovery Receipt Validation

Status: proposed

- Acute Care never shows a clinical form.
- A receipt cannot start without an explicit saved Care record.
- Mode suggestions remain visibly editable candidates.
- Skip and back paths save no partial clinical values.
- Same-day and later-recall provenance is correct across local date changes.
- No interaction behavior becomes a severity or impairment score.
- Receipt values appear in local history with edit and delete support.
- 320px, 200 percent text, reduced motion, and screen-reader paths work.
